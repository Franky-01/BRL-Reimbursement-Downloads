Windows and both Mac installers are published together for every delivered change. Python and Chinese/English OCR are included. Source code stays private.

On Mac, open the DMG and drag BRL Reimbursement into Applications. The minimum target is macOS 13; native tests ran on macOS 15. The Mac app has ad hoc signing and has not been Apple-notarized. First-launch instructions: [Apple guide](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).

Put invoice PDFs and item photos in one folder, choose that folder, and generate documents. Review and sign the Word documents before approving photo cleanup. Use Language / 语言 to switch languages. PDFs are kept, previous documents are backed up, and photos are kept until cleanup is approved.

Use Check updates inside the app. Downloads do not require GitHub login. SHA256SUMS.txt and release-manifest.json identify all installers and the verified build. Packages contain the application and clean templates, without historical invoices, photos, signatures or credentials.
