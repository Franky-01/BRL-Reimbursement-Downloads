# BRL 报销助手

[English](README.md) | **中文**

本仓库提供 Windows 安装包和更新，源代码保持私有。

**最新版 1.3.0**：[下载安装包](https://github.com/Franky-01/BRL-Reimbursement-Downloads/releases/download/v1.3.0/BRL-Reimbursement-Setup-1.3.0.exe) · [最新发布](https://github.com/Franky-01/BRL-Reimbursement-Downloads/releases/latest)

1. 把 PDF 发票和实物照片放进同一个文件夹。
2. 选择文件夹，点击“生成报销文档”。
3. 打开清单及服务确认单（如有），核对后自行签名。
4. 确认内容完整无误后，可点击“删除原图片”。

软件默认英文，左侧 **Language / 语言** 可切换 **中文**，下次启动会保留选择。报销文档使用原有双语模板和原文件名。

在软件中检查更新、下载安装包即可，不需要 GitHub 登录或跳转网页。原图只在核对确认后清理，已有同名文档会先备份。

安装包仅包含程序与清理后的模板，不包含历史票据、实物照片、签名或凭据。
